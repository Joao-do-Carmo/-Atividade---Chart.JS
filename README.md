# 📚 Dashboard com Chart.js – Atividade Acadêmica

Este projeto foi desenvolvido como parte de uma **atividade prática em sala de aula** da faculdade, com o objetivo de aplicar os conhecimentos de **HTML**, **CSS** e **JavaScript** utilizando a biblioteca **Chart.js**.

A proposta consistia em criar uma página HTML que exibisse dois gráficos:

- Um **gráfico de linhas** representando dados de temperatura e umidade por horário.
- Um **gráfico de barras** exibindo as médias mensais de temperatura e umidade.

Todos os dados utilizados foram fornecidos pelo professor e são **mockados** (simulados), apenas para fins de visualização e aprendizado.

---

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- [Chart.js](https://www.chartjs.org/)

---

## 📌 Observações

- Esta é uma atividade acadêmica sem fins comerciais.
- O objetivo principal é a familiarização com bibliotecas de visualização de dados para aplicações web.
